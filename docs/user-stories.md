## 一、老人端故事（使用者：张秀兰）

### 优先级 P0

| 编号 | 用户故事 | 验收要点 |
|------|----------|----------|
| US-ELDER-001 | 作为老人，我收到微信消息提醒后，点击消息就能看到今天该吃什么药，不用打开任何 App | 消息内容清晰列出药品名称+剂量，点击直达确认页 |
| US-ELDER-002 | 作为老人，我吃完药后点一下「已服用」按钮就好，不需要填任何东西 | 一个大按钮，点击即完成，2 秒内给反馈 |
| US-ELDER-003 | 作为老人，如果我发现自己忘了吃药，可以点「未服用」并选择原因 | 提供预设原因选项（忘记/不舒服/药没了/其他） |
| US-ELDER-004 | 作为老人，如果医生让我今天停某个药，我可以临时跳过这次 | 跳过需要选择原因，并通知子女 |

### 优先级 P1

| 编号 | 用户故事 | 验收要点 |
|------|----------|----------|
| US-ELDER-005 | 作为老人，如果我点错了「已服用」，可以马上撤销（5 分钟内） | 确认后显示「撤销」入口，5 分钟后自动消失 |
| US-ELDER-006 | 作为老人，我想看一下我今天已经吃了哪些药、还有哪些没吃 | 简单的列表页面，已吃=绿色，待吃=黄色 |
